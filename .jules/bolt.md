## 2025-02-12 - [Lazy Loading Large Tooling UI Components]
**Learning:** Heavy, data-rich UI components like `EmojiPicker` (which internally depends on massive datasets such as `@emoji-mart/data` and many nested components) can significantly increase the initial bundle size if imported eagerly. Additionally, even if these components are rendered inside a conditionally rendered container (like a Popover/Dropdown), if they are imported eagerly, they block the main execution flow and negatively impact time-to-interactive.
**Action:** Use `next/dynamic` to lazy-load heavy UI components that are not needed immediately on initial page load (e.g. components that only appear when a user clicks a toolbar button). Include a fallback placeholder that mimics the exact layout dimensions of the loaded component (`loading: () => <div className="h-[23rem] w-80" />`) to prevent layout shift.
